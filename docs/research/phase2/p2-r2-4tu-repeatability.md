# R2 • Twente running sessions and P2-B0

The authors report one endurance run, one interval session and one submaximal 5 km on separate days per runner. The study used Garmin TCX export, watch and strap at 1 Hz and synchronized IMUs recorded at 120 Hz. The publication allows a design comparison. No original archive member, athlete pair or missingness rate was verified.

| Question | Applicability | Reason |
|---|---|---|
| Compare measurement demands across session types | DIRECT for published design | HR, perceived effort and biomechanical load measure different aspects. |
| Speed at comparable HR or HR at comparable speed | PARTIAL | Exploratory within-session windows could be computed after file admission. Fixed-route, preselected repeated easy efforts and the B0 comparator are missing. |
| Drift or decoupling | PARTIAL | Endurance data could support descriptive change with elapsed time, segment boundaries, stops and clock checks. Interval rest distorts this estimate. |
| GPS/HR sampling gaps | PARTIAL | Count observed intervals per device and session after archive inspection. Nominal rate supplies no missingness estimate. |
| Absolute GPS error, chest HR error or improvement over weeks | NOT_APPLICABLE | No verified independent distance/beat criterion or repeated longitudinal easy protocol. |
| IMU repeatability as evidence for matched-HR speed | INDIRECT | Different endpoint. |
| Registered between-day typical error in m/s | NOT_APPLICABLE | One END opportunity per participant by design. Pooling INT and 5K would conflate session type with day. |

The authors found perceived load differentiated sessions that their physiological and biomechanical summaries did not. This cautions against interchangeable load inputs. It supplies neither a matched-HR typical error nor a minimum useful pace change. P2-B0 remains protocol-ready/data-not-ready. Use prospective S1 linked repeats, registered 20-minute segments and matched comparator pairs before estimating B0 typical error. The existing p2_trace decoder handles a deliberately narrow one-lap dialect. Its acceptance is insufficient to establish archive coverage or B0 eligibility.

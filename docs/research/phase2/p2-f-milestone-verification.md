## What the code actually established

- **TCX:** The integrated probe binds original bytes and reference digest to one verified edge, checks the performed interval, and handles one namespace-v2 Running activity, one lap and one track. The original ID is an offset-bearing instant equal to `Lap/@StartTime`. Original fixtures contain point time, distance and optional HR. The registered QC result requires a separately supplied reference, timer history and marker evidence. The parser does not establish independent reference truth, device support, native timer duration or sensor model. A targeted synthetic check reproduced that malformed lap-summary time/distance and malformed cadence text could be present without rejection: those original fields were ignored. Do not count them as reconciled.
- **FIT:** Separate synthetic reader for selected session, record and timer fields; native FIT input never reaches the linked TCX probe or B0. Tests use generated bytes and exercise CRC, truncation, ambiguous ownership and timer cases. They do not document a common real exporter or constitute external decoder parity.
- **GPX:** Checks dialect and segment count, then quarantines even a single segment for insufficient distance/timer evidence. No GPX registered measurement or stitched activity exists.
- **Linkage:** In-memory, scoped replay and withdrawal tests exercise synthetic trusted events, not operational custody, physical deletion, independent identity proof, or a participant's approval.

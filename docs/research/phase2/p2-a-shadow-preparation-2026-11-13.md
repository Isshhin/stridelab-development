# P2-A synthetic shadow preparation — 2026-11-13

This additive helper is isolated from the frozen Session G baseline and the B0/H1 comparison runner. It accepts invented observations only; it is not a calibrated athlete-state model, does not estimate readiness or coaching benefit, and emits no training action.

`research/validation/p2a_shadow.py` filters observations by `available_at <= decision_at`, validates timezone-aware event/observed/available ordering and unique IDs, requires and returns Session G athlete/discipline/event/source/version/protocol/device/rights/plan-revision lineage, rejects mixed athlete/discipline or visible history units, and reports included IDs, excluded quality/value count, support, newest-input age and model version. Visible values require a nonempty string unit; malformed unit labels fail closed. Non-finite values and integers too large for the finite-number check are excluded (or make a check-in unavailable) instead of poisoning the descriptive result. It does not impose an unsupported freshness threshold; age is reported for later protocol-defined handling. With fewer than two valid history values it abstains without a descriptive median. It compares history-only with history-plus-check-in as separate views. A check-in is included only if reported and available at decision time; because its scale is not calibrated to history, that view explicitly abstains and emits no mixed-unit median. Missing or delayed check-ins do not alter the history-only result.

Synthetic regressions cover delayed arrival despite earlier observation, check-in ablation, sparse/invalid history, duplicate identities, incompatible units, missing lineage, and isolated interaction with existing policy proposals and hard restrictions. No P2-A output is fed into B0/H1: there is no validated shared temporal/provenance contract for that integration. These tests prove only code behavior. They do not establish real linkage, meaningful uncertainty calibration, an appropriate sample minimum, predictive value, or effectiveness. P2-A remains shadow research pending authorized decision-time inputs and independent follow-up; P2-B repeatability remains required for any matched-efficiency feature.

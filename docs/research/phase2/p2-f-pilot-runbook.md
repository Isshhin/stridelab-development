Do not paste an export, screenshot, diary, private receipt, digest or personal identifier into a repository, AI session, online viewer, issue, CI log or tracker. Maintain the private worksheet only in the approved offline study environment.

## Private reference: order of work and blind seal

Use the [blank audit forms](p2-f-private-audit-worksheets.md) in an approved offline workspace. Only blank forms belong here. Assign a reference reviewer who cannot read the harness output, parser-derived IDs, diagnostics, discrepancy log or previous comparison for this source. The custodian supplies only the authorized immutable source and independently dated diary, plan/receipt journal and reviewed identity evidence. Do not let the source file establish its own trusted owner, bout, or plan link. The reviewer inventories every in-scope opportunity and incoming observation before the operator reveals any results.

Choose the first usable method in this order for each channel: (1) independently implemented offline viewer/decoder; (2) trusted offline vendor viewer with documented field semantics and known decoding lineage; (3) separately implemented parser; (4) manual TCX XML inspection of the original, recording namespace, field path and session/lap/track/point ordinal. Record exact tool/version, dependencies, provenance, offline configuration and reason for any fallback. A wrapper or another invocation of the same decoder, exported harness tables, shared parsing/normalization logic, or an expectation reconstructed after seeing output is not independent. Shared or unknown decoder ancestry disqualifies that channel unless independently inspected by another method. If no independent reading is possible, mark reference unavailable; do not score agreement.

For TCX, follow each Activity, Lap, Track and Trackpoint in document order; compare complete ordinal membership, first/last point, source offset and normalized instant, and all authorized timestamped channels. Record gaps at track boundaries; do not bridge them. Distinguish point-clock span from lap-reported duration, elapsed from timer, and source cadence units from steps/min. Inspect no coordinates for this comparison. Record native unit, resolution, rounding and allowed conversion **before** unblinding. Compare categorical values, membership, chronology and missingness exactly. For numeric fields compare exactly at known native precision or use the predeclared documented rounding interval; unknown semantics or precision cannot produce a passing numeric comparison. Do not infer moving time, pause, sensor model, speed, or environment from silence. This comparison does not apply the B0 segment selection or compute a repeatability outcome.

Freeze the completed reference, roster, scoring rules, method and cutoffs in a private read-only version. Record its private digest, reviewer, sealing time and custodian acknowledgement. Only then release comparison access; record the first exposure time and verify the seal. If one person holds multiple roles, record the overlap, prior exposure and the private file-access sequence; seal the reference before running the harness. This reduces reviewer independence even if the decoder is independent; it cannot substitute for independent clearance. If contamination predates the seal, quarantine the comparison. Arrange a fresh blinded reviewer or leave it unscorable. Never relabel an unblinded correction as a blinded reference.

## Private worksheet and disclosure

Use one row per opportunity, one per incoming observation (including aliases), and a discrepancy row per field/edge. Include private scoped IDs, revision and clock basis, reference/observed values and units, availability, eligibility or abstention, provenance, reviewer and dates, severity, disposition, correction lineage, minutes spent extracting/verifying/adjudicating and outstanding work. Preserve the initial comparison. Independently record missing exports, manual-only activities, unmatched files, late/partial/duplicate rows, declined context, not-due and overdue follow-up. Do not infer a skip or failure from silence.

Compute separately (i) correctly linked eligible opportunities / **all audited eligible opportunities** and (ii) correct source-to-actual identities / **all audited incoming observations**; enumerate rejected/quarantined/missing counts without quietly removing failures. Mark zero denominators unavailable. Report audit minutes per row and total setup/adjudication minutes separately. Privately stratify by device, firmware, format and parser epoch. One export bounds only that observed path and cannot supply reliable population estimates or practical thresholds by itself.

Any silent critical mismatch (wrong account/revision, unauthorized or future-visible item, double dose, broken partition or withdrawn data exposed) stops the affected device/source path and dependent outputs. Isolate, preserve evidence privately and notify the steward. Ambiguous identity, units, timing or reference: quarantine and retain denominator and reason; escalate if an eligible calculation used it. Document harmless display/rounding differences too. Restart only after a versioned correction, new applicable grant if needed and independent replay/clearance; never open held-out data to resolve ambiguity.

Git may receive **only non-identifying structured results after disclosure review**: engineering check/pass/fail/unsupported, severity classes, safe aggregate coverage and burden or “suppressed,” open defects and path disposition. No private hashes, paths, serials, exact dates/times, rare configuration combinations, comparison values, identifiers, coordinates, credentials or consent. If even counts identify the sole participant, leave exact counts in the restricted audit and publish only a process disposition. Leave margins unresolved when pilot evidence is insufficient. This runbook does not release Gate 2, enable active P2-B analysis or change Session G.

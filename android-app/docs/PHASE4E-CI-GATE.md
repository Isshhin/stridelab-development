# One official Phase 4E Android gate

Private workflow in `Isshhin/stridelab-development`:
`https://github.com/Isshhin/stridelab-development/actions/workflows/phase4e-final-android.yml`

The workflow downloads this exact private release candidate, verifies ZIP hash and every manifest entry; downloads the independently accepted Phase 4D ZIP from its immutable private release; compares every bundled exercise image and the complete HTML script code against Phase 4D; verifies no Internet permission and protected coaching engine; then uses GitHub's Android SDK to build the Android APK, execute JUnit backup tests, and launch it in an Android emulator for on-device instrumentation tests. It uploads a private **debug APK artifact** (ephemeral signature) and, only if privately configured signing secrets are present, a private **release APK artifact** with a durable signature.

`Phase 4E` is not accepted merely because compilation succeeds. It is only **automated-accepted** when these steps succeed. Full physical-device acceptance requires the separate manual checklist in `PHASE4E-IMPLEMENTATION.md` and a stable signed install/update trial. Debug Android artifacts generated by distinct ephemeral GitHub runners generally do not update each other in place.

**No signing key, real-user training data or personal backup should be published in any release source ZIP.**
